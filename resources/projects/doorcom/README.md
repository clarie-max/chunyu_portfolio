## Scope and imagery

The current first chapter has five stages: PawsAndWhiskers, KitchenChronicles, SoundOn, LikeMe, InOrOut. The final stage branches between multiplying robot-verification prompts and a ladder/falling/screen-off exit. Closing the application is a game behavior, not an action taken by the website.

The user-published gameplay demo is https://youtu.be/L7IZA6z1K0A, embedded below the introduction with the YouTube privacy-enhanced player. `demo.mp4` is retained as source material and is no longer loaded by the webpage. `door-mark.svg` remains the project listing graphic, not artwork from the team and not a gameplay screenshot. No runtime playtest, measured playtime, evaluation outcomes, or playable build is claimed.
